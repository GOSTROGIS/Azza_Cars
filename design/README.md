# Design system

Tokens and components for the Azza Cars website and dashboard: bone white, carbon black and a vivid
blood orange, with real depth (layered surfaces, bevel highlights, stacked shadows).

| File | What it is |
|---|---|
| `tokens.css` | CSS custom properties: colour primitives, semantic tokens per theme (`carbon` default, `bone`), type, space, radii, depth, motion |
| `components.css` | Components with the `az-` prefix: panel, card, button, input, chip, segmented control, badge, kbd, listbox option, brand tile, stat, notice |
| `specimen.html` | Visual specimen of everything above. Open it from a local web server at the repo root so the logo images load |
| `contrast.md` | Generated by `tools/design/contrast.py`. WCAG contrast for every text pairing in both themes |

## Principles

- **Three colours.** Bone (`--bone-*`), carbon (`--carbon-*`) and blood orange (`--orange-500` #ff4b1f).
  On bone, orange text uses the darker ink `--orange-800` so it stays readable. Primary buttons are orange with carbon text.
- **Depth levels.** Recessed inputs, then panel, card and control. Each raised level adds a top bevel
  highlight (`--bevel`), a sheen gradient (`--sheen`) and a larger shadow (`--shadow-1` to `--shadow-3`).
  Selection glows orange (`--glow-accent`).
- **Type.** Archivo (wide, heavy) for display, Inter for body, JetBrains Mono for data. The site self-hosts them through Fontsource.
- **Accessible by default.** All body-text pairings pass WCAG AA (4.5:1) in both themes. Focus is a visible
  two-ring outline. Motion turns off under `prefers-reduced-motion`.
- **Honesty.** Logos appear only after the logo audit. Otherwise a tile shows the brand name in clean type
  and "Logo pending audit". 3D vehicles carry a "recreation, not factory CAD" label.

## Checks

```
python3 tools/design/contrast.py   # writes design/contrast.md, exits 1 if a pairing fails
```
