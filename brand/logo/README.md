# brand/logo

The Ember Rent mark: an ignition ring opening clockwise, with a glowing ember where the key turns.

| File | Use |
|---|---|
| `ember-mark.svg` | Mark on light backgrounds |
| `ember-mark-bone.svg` | Mark on dark backgrounds |
| `ember-app-icon.svg` | App icon and favicon (copied to `site/public/favicon.svg`) |
| `ember-lockup-carbon.svg` | Mark and wordmark on carbon |
| `ember-lockup-bone.svg` | Mark and wordmark on bone |

The wordmark is set in Archivo (SIL Open Font License), width 125, weight 900. The lockups use live text, so convert it to outlines before print or signage use.

The name still needs a trademark agent's CIPO and USPTO search before filing (see `brand/NAMING.md`).
